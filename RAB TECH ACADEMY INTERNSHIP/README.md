## Highlights of Model & Engineering Performance

1. **Responsible AI Governance (Problem 2):**
   - Asymmetric financial loss optimization ($C_{FP} = \$450, C_{FN} = \$14,800$) shifts operating threshold to $\tau^* = 0.227$, saving **$193,160 per 1,000 discharges** (~$2.9M annually) over the clinical LACE baseline.
   - Verified Four-Fifths fairness rule compliance ($DIR \ge 0.80$) across all protected demographics.
2. **Leak-Free Tabular Preprocessing (Problem 3):**
   - Scikit-Learn `ColumnTransformer` with cross-fitted `TargetEncoder(cv=5)` compressed 35 sub-grades into a dense high-signal feature without sparse explosion or target leakage.
3. **Champion Model Benchmark (Problem 4):**
   - LightGBM led across all metrics with **0.8695 Test ROC-AUC**, **0.6720 PR-AUC**, and **0.1124 Brier score** at **~21 $\mu\text{s}$ inference latency**.
4. **Deep Learning NLP (Problem 5):**
   - PyTorch feed-forward architecture with `BatchNorm1d` and `Dropout` achieved **98.50% test accuracy** and **0.998 ROC-AUC** with automated `EarlyStopping` checkpoint restoration.
5. **Production Microservice (Problem 6):**
   - FastAPI REST API with Pydantic v2 schemas, sub-millisecond scoring, non-root secure Docker container, and 100% automated test pass rate via `pytest`.
